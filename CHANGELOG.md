# Changelog

All notable changes to SENTINEL are documented here. The format follows Keep a Changelog and uses semantic versioning.

## [1.0.0] - 2026-08-27

### Added

- Persistent asset, event, detection rule, alert, ScenarioRun, network relationship, Incident, AI-analysis, and investigation-message models with Alembic history.
- Genuine bundled Corporate Lab telemetry and a controlled five-scenario Purple Team workflow.
- Evidence-backed Attack Map and deterministic Incident correlation/story reconstruction.
- Optional bounded, redacted, grounded Investigation Assistant with local mock and OpenAI provider adapters.
- Professional point-in-time Incident export in self-contained HTML and printable PDF.
- Dashboard ranges, recent Incident workflow, version/build context, intentional 404/error recovery, demo guidance, and development-only guarded reset.
- Complete getting-started, configuration, demo, reporting, portfolio, security, architecture, API, release notes, and release checklist documentation.

### Security

- Loopback-only host ports, internal lab networks, unprivileged containers, separate trust keys, bounded inputs, safe YAML, evidence escaping, and restrictive HTML-report headers.
- Conservative ATT&CK mapping: unexpected database connections remain unmapped rather than implying data collection.

### Known limitations

- Experimental single-instance local platform without production authentication, RBAC, TLS termination, durable queues, retention policy, distributed coordination, or forensic certification.
